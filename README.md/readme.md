# 🏥 CareFlow AI

## AI-Powered Healthcare Appointment & Queue Management System

### 📌 Project Overview
CareFlow AI is a healthcare assistant that helps patients register, analyze symptoms, book appointments, generate tokens, estimate waiting time, and maintain medicine history.

## ✨ Features

- 👤 User Registration
- 🔐 User Login
- 🩺 Symptom Analysis
- 🤖 AI Specialist Recommendation
- 📅 Appointment Booking
- 💳 Payment Module
- 🎫 Token Generation
- ⏳ Waiting Time Prediction
- 📩 SMS Reminder
- 💊 Medicine History
- 📜 Patient History

## 🛠️ Technologies Used

- Python
- Streamlit
- FastAPI
- Pandas
- NumPy
- Scikit-learn
